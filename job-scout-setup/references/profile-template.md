# profile.md template

Fill from the CV and the interview. Only facts the person gave. Delete lines that do not apply (hours, for example, if they only want full-time). Keep it short: every run reads it.

```markdown
# Job search profile: {{FULL_NAME}}
Last confirmed: {{DATE}}

## Target
- Roles, best first: {{ROLES_RANKED}}
- Fields or sectors, best first: {{FIELDS_RANKED}}
- Level and contract: {{LEVEL}}; {{CONTRACT_TYPES}}
- Hours per week (if relevant): {{HOURS}}
- Location: {{CITY}}, commute up to {{COMMUTE}}; remote: {{REMOTE_OK}}; relocation: {{RELOCATION}}
- Start: {{START_WINDOW}}
- Minimum pay: {{MIN_PAY}}
- Deadlines matter: {{YES_NO}}; known application windows: {{WINDOWS}}

## Background (from the CV)
- Education: {{EDUCATION}}
- Experience: {{EXPERIENCE_SHORT}}
- Skills: {{SKILLS}}
- Languages: {{LANGUAGES_WITH_LEVELS}}
- Projects, publications, certificates: {{PROJECTS}}

## Work authorization
{{WORK_AUTH}}

## Scoring rules
Score 5: {{PERFECT_JOB}}
Score 4: one stretch, e.g. a detail not stated but plausible, or a cannot-claim item named only as an advantage.
Score 3: weaker but worth a glance: {{SCORE_3_EXAMPLES}}
Hard no (never report): {{HARD_NOS}}
Cannot claim (a posting that REQUIRES one of these scores 3 at most; as "nice to have" it does not count): {{CANNOT_CLAIM}}
Detail-page keywords (open the posting when the title has one): {{KEYWORDS_ALL_LANGUAGES}}

## Fact guardrails (override everything else)
- {{NEVER_CLAIM}}

## Employers
- Exclude: {{EXCLUDED}}
- Watch closely: {{WATCH_LIST}}
- Separate employers, do not merge: {{SEPARATE}}

## Outreach (only if on)
- Sign-off: {{NAME}}, {{PHONE}}, {{LINK}}
- Languages: {{LANGUAGES}}
- Target organisations: {{TARGETS}}
```
